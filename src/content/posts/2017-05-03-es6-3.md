ES6 시리즈의 마지막 편에서는 **자료구조, 내장 유틸리티 메서드, 비동기 `Promise`, 메타 프로그래밍(`Proxy`/`Reflect`), 그리고 `Intl` 국제화 API**를 다룹니다.

## 컬렉션 자료구조: Set, Map, WeakMap, WeakSet

기존 JavaScript에서는 해시맵이나 집합이 필요할 때 일반 객체 `{}`나 배열을 우회적으로 사용했지만, 키가 문자열로 변환되거나 프로토타입 키(`toString` 등)와 충돌하는 한계가 있었습니다.

### `Set` — 중복 없는 값의 집합

```js
const tags = new Set(["js", "web", "js"]);
tags.add("node");

console.log(tags.size);        // 3
console.log(tags.has("web"));  // true

// 배열 중복 제거 실전 패턴
const unique = [...new Set([1, 2, 2, 3, 3])]; // [1, 2, 3]
```

### `Map` — 모든 타입을 키로 쓰는 키-값 저장소

`Map`은 문자열뿐 아니라 **객체, 함수, 원시값 모두를 키로 사용**할 수 있으며, 삽입 순서를 보장하고 `.size`를 상수 시간($O(1)$)에 조회합니다.

```js
const metaMap = new Map();
const userObj = { id: 1 };

metaMap.set("role", "admin");
metaMap.set(userObj, { lastLogin: "2026-01-01" });

console.log(metaMap.get(userObj)); // { lastLogin: "2026-01-01" }
for (const [key, value] of metaMap.entries()) {
  console.log(key, value);
}
```

### `WeakMap`과 `WeakSet` — 메모리 누수 없는 약한 참조

`WeakMap`의 키(객체만 가능)와 `WeakSet`의 요소(객체만 가능)는 **약한 참조(Weak Reference)** 로 유지됩니다. 즉, 해당 객체에 대한 다른 참조가 모두 사라지면 **가비지 컬렉터(GC)가 자동으로 메모리를 회수**합니다.

- DOM 노드에 부가 메타데이터를 연결하거나, 클래스 외부에서 인스턴스 캐시/비공개 상태를 관리할 때 유용합니다.
- GC 대상 여부가 비결정적이므로 `.size`나 순회(`for...of`) 메서드는 제공되지 않습니다.

```js
const privateCache = new WeakMap();

class DocumentParser {
  parse(doc) {
    if (privateCache.has(doc)) {
      return privateCache.get(doc);
    }
    const result = { length: doc.content.length };
    privateCache.set(doc, result);
    return result;
  }
}
```

## 실무에서 자주 쓰는 ES6 내장 메서드

```js
// 1. 객체 병합: Object.assign (현대 코드에서는 Spread {...a, ...b}도 자주 사용)
const target = { a: 1 };
Object.assign(target, { b: 2 }, { a: 3 }); // { a: 3, b: 2 }

// 2. 배열 요소 탐색: find / findIndex
const users = [{ id: 1, name: "A" }, { id: 2, name: "B" }];
const found = users.find(u => u.id === 2); // { id: 2, name: "B" }

// 3. 문자열 검색 및 반복
console.log("hello world".startsWith("hello")); // true
console.log("hello world".endsWith("world"));   // true
console.log("hello world".includes("lo wo"));   // true
console.log("ha".repeat(3));                    // "hahaha"

// 4. 안전한 숫자 판별 및 부동소수점 오차 비교
console.log(Number.isNaN("NaN")); // false (전역 isNaN("NaN")과 달리 형 변환 없음)
console.log(Number.isFinite(Infinity)); // false
console.log(Number.isSafeInteger(9007199254740991)); // true (Number.MAX_SAFE_INTEGER)

// 0.1 + 0.2 === 0.3 은 false 이므로 Number.EPSILON 활용
const isEqualFloat = Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON; // true
console.log(Math.trunc(42.7), Math.sign(-7)); // 42, -1
```

## Typed Arrays (이진 데이터 처리)

`ArrayBuffer`와 `Uint8Array`, `Float32Array` 같은 Typed Array는 고정 길이의 원시 바이너리 버퍼를 다룹니다. WebGL 그래픽 처리, WebSocket 바이너리 프로토콜, 파일/이미지/암호화 처리에 필수적입니다.

## Promise와 비동기 조합 (`async`/`await`까지)

ES6의 `Promise`는 비동기 작업의 최종 완료(또는 실패)와 결과값을 나타내는 객체입니다. 콜백 함수가 깊게 중첩되는 콜백 지옥을 평탄한 체이닝으로 바꿨습니다.

```js
function delayMessage(msg, timeout) {
  return new Promise(resolve => {
    setTimeout(() => resolve(msg), timeout);
  });
}

// Promise 체이닝
delayMessage("Hello", 100)
  .then(msg => delayMessage(`${msg} ES6`, 100))
  .then(result => console.log(result));

// async / await (ES2017)로 더 직관적인 표현
async function runParallel() {
  const [first, second] = await Promise.all([
    delayMessage("Task 1", 100),
    delayMessage("Task 2", 150),
  ]);
  console.log(first, second);
}
```

> [!TIP]
> 여러 비동기 작업을 병렬 실행할 때 하나라도 실패하면 전체가 거절되어야 한다면 `Promise.all()`, 일부가 실패해도 모든 결과를 확인해야 한다면 ES2020의 `Promise.allSettled()`를 사용하세요.

## 메타 프로그래밍: `Proxy`와 `Reflect`

`Proxy`는 객체의 기본 동작(프로퍼티 조회, 할당, 삭제, 함수 호출 등)을 가로채 커스텀 로직을 삽입할 수 있게 해줍니다. 반응형 상태 관리(예: Vue 3의 Reactivity 시스템)나 유효성 검증에 널리 쓰입니다.

```js
const target = { name: "Steve", age: 30 };

const validatedUser = new Proxy(target, {
  get(obj, prop, receiver) {
    return prop in obj ? Reflect.get(obj, prop, receiver) : `Unknown(${String(prop)})`;
  },
  set(obj, prop, value, receiver) {
    if (prop === "age" && (typeof value !== "number" || value < 0)) {
      throw new TypeError("나이는 0 이상의 숫자여야 합니다.");
    }
    return Reflect.set(obj, prop, value, receiver);
  },
});

console.log(validatedUser.name);    // "Steve"
console.log(validatedUser.unknown); // "Unknown(unknown)"
// validatedUser.age = -5;          // TypeError 발생
```

## 국제화와 지역화 (`Intl`)

외부 라이브러리 없이도 브라우저와 Node.js 내장 `Intl` API만으로 국가·언어별 정렬, 숫자/통화 포맷팅, 날짜 포맷팅을 정확하게 처리할 수 있습니다.

```js
// 1. 로케일 기반 문자열 비교/정렬
const deCollator = new Intl.Collator("de");
console.log(["ä", "a", "z"].sort(deCollator.compare)); // ["a", "ä", "z"]

// 2. 숫자 및 통화 포맷팅
const krwFormatter = new Intl.NumberFormat("ko-KR", {
  style: "currency",
  currency: "KRW",
});
console.log(krwFormatter.format(1250000)); // "₩1,250,000"

// 3. 날짜/시간 포맷팅
const koDate = new Intl.DateTimeFormat("ko-KR", { dateStyle: "long" });
console.log(koDate.format(new Date("2024-05-03"))); // "2024년 5월 3일"
```

## 시리즈를 마치며

ES6는 단순한 문법 추가를 넘어 **스코프 안정성(`let`/`const`), 모듈 시스템(ESM), 표준 비동기 모델(`Promise`), 컬렉션과 메타 프로그래밍**을 JavaScript에 정착시켰습니다. 이 기반을 탄탄히 다져두면 이후 등장한 최신 ECMAScript 기능과 TypeScript, 주요 프레임워크를 훨씬 수월하게 이해할 수 있습니다.
