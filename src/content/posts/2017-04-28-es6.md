**ES6(ECMAScript 2015)** 는 JavaScript 역사상 가장 큰 도약을 이룬 표준입니다. 이후 매년 ES2016, ES2017... 형태로 버전이 올라갔지만, 오늘날 우리가 작성하는 모던 JavaScript 문법의 대다수는 바로 이 ES6에서 출발했습니다.

시리즈 1편에서는 **변수 스코프, 함수, 파라미터 처리, 문자열·리터럴 확장**을 실전 코드 중심으로 살펴봅니다.

## 블록 스코프와 상수 (`const`, `let`)

기존 `var`는 함수 단위로만 스코프가 격리되어 `if`나 `for` 블록 내부 변수가 바깥으로 새어 나가는 문제가 있었습니다. ES6에서는 블록(`{ ... }`) 단위로 스코프가 제한되는 `let`과 재할당이 불가능한 `const`가 도입되었습니다.

```js
const MAX_RETRY = 3;

for (let i = 0; i < MAX_RETRY; i++) {
  // i는 이 for 블록 내부에서만 유효
}
// console.log(i); // ReferenceError: i is not defined
```

> [!TIP]
> `const`는 변수 자체의 **재할당(Reassignment)** 을 막을 뿐, 객체나 배열의 내부 값까지 불변(Immutable)으로 만들지는 않습니다. 객체의 수정 자체를 막아야 한다면 `Object.freeze()`나 불변 업데이트 패턴(`{ ...obj, key: newValue }`)을 함께 사용하세요.

## 화살표 함수(Arrow Functions)

화살표 함수는 짧은 문법뿐만 아니라 **`this` 바인딩 방식**에서 일반 함수와 결정적인 차이를 가집니다.

### 1. 간결한 본문 표현

```js
const evens = [2, 4, 6, 8];

const odds = evens.map(v => v + 1); // [3, 5, 7, 9]
// 객체 리터럴을 암시적 반환할 때는 소괄호 ()로 감싸야 블록과 구분됨
const pairs = evens.map(v => ({ even: v, odd: v + 1 }));
```

### 2. Lexical `this` 바인딩

일반 함수는 호출 주체에 따라 `this`가 동적으로 바뀌어 `const self = this` 같은 우회 코드가 필요했습니다. 반면 **화살표 함수는 자신만의 `this`를 갖지 않고 상위 스코프의 `this`를 그대로 물려받습니다(Lexical `this`)**.

```js
class Counter {
  constructor() {
    this.nums = [1, 5, 10, 12, 15];
    this.fives = [];
  }

  collectFives() {
    this.nums.forEach(v => {
      if (v % 5 === 0) {
        this.fives.push(v); // 상위 메서드(collectFives)의 this를 그대로 참조
      }
    });
  }
}

const counter = new Counter();
counter.collectFives();
console.log(counter.fives); // [5, 10, 15]
```

> [!WARNING]
> 화살표 함수는 생성자로 사용할 수 없고(`new` 불가), 자체 `arguments` 객체도 가지지 않습니다. 또한 객체의 메서드나 DOM 이벤트 콜백에서 동적 `this`가 필요한 경우에는 일반 함수 문법을 써야 합니다.

## 확장된 파라미터 처리

### 기본 매개변수 (Default Parameters)

인자가 전달되지 않거나 `undefined`일 때 사용할 기본값을 선언부에서 바로 지정할 수 있습니다.

```js
function calculatePrice(price, taxRate = 0.1, discount = 0) {
  return price * (1 + taxRate) - discount;
}

console.log(calculatePrice(1000));             // 1100
console.log(calculatePrice(1000, undefined, 100)); // 1000 (undefined 전달 시 기본값 적용)
```

### Rest 파라미터와 Spread 연산자 (`...`)

같은 `...` 문법이지만 **위치에 따라 정반대 역할**을 합니다.

- **Rest 파라미터**: 함수 인자 목록 끝에서 남은 인자들을 **하나의 배열로 묶음**
- **Spread 연산자**: 배열이나 이터러블을 **개별 요소로 펼침** (배열/객체 얕은 복사 및 병합에 매우 유용)

```js
// Rest: 가변 인자를 배열로 수집
function multiplySum(multiplier, ...numbers) {
  return multiplier * numbers.reduce((acc, n) => acc + n, 0);
}
console.log(multiplySum(2, 1, 2, 3)); // 12

// Spread: 배열/객체 펼치기
const base = [1, 2];
const combined = [...base, 3, 4]; // [1, 2, 3, 4]

const defaults = { theme: "light", lang: "ko" };
const userConfig = { ...defaults, theme: "dark" }; // { theme: "dark", lang: "ko" }
```

## 템플릿 리터럴 (Template Literals)

백틱(`` ` ``)을 사용해 여러 줄 문자열(Multi-line)과 표현식 보간(`${expression}`)을 직관적으로 작성할 수 있습니다.

```js
const customer = { name: "Steve" };
const item = { count: 3, name: "Keyboard", price: 120000 };

const summary = `안녕하세요, ${customer.name}님.
주문하신 ${item.name} ${item.count}개의 총액은 ${(item.count * item.price).toLocaleString()}원입니다.`;
```

### Tagged Template Literals와 `String.raw`

함수 뒤에 백틱을 바로 붙이면 문자열 조각과 보간 값들을 인자로 받아 커스텀 처리(XSS 이스케이핑, SQL 파라미터 바인딩, CSS-in-JS 등)를 할 수 있습니다.

```js
function highlight(strings, ...values) {
  return strings.reduce(
    (result, str, i) => `${result}${str}${values[i] !== undefined ? `[${values[i]}]` : ""}`,
    ""
  );
}

const lang = "ES6";
const year = 2015;
console.log(highlight`표준 ${lang}은 ${year}년에 발표되었습니다.`);
// "표준 [ES6]은 [2015]년에 발표되었습니다."

// 이스케이프 문자(\n 등)를 해석하지 않고 원문 그대로 유지
console.log(String.raw`C:\new_folder\test.txt`); // "C:\new_folder\test.txt"
```

## 확장 리터럴과 유니코드·정규식 개선

- **2진수·8진수 리터럴**: `0b111110111 === 503`, `0o767 === 503`으로 명확히 표기할 수 있습니다.
- **유니코드 코드 포인트 지원 (`u` 플래그)**: 서로게이트 페어(Surrogate Pair)로 구성된 이모지나 특수 한자도 정확히 인식합니다.

```js
const char = "𠮷";
console.log(char.length);               // 2 (UTF-16 코드 유닛 기준)
console.log([...char].length);          // 1 (실제 문자 1개 단위 이터레이션)
console.log(char === "\u{20BB7}");      // true
console.log(/^.$/u.test("🚀"));         // true (u 플래그가 없으면 false)
```

- **Sticky 정규식 매칭 (`y` 플래그)**: `lastIndex` 위치에서 정확히 이어지는 패턴만 매칭하므로 렉서(Lexer)나 토크나이저를 작성할 때 성능과 정확도가 높습니다.

```js
const tokenPattern = /\s*([a-zA-Z]+|\d+)/y;
const input = "Foo 1 Bar 7";
const tokens = [];

let match;
while ((match = tokenPattern.exec(input)) !== null) {
  tokens.push(match[1]);
}
console.log(tokens); // ["Foo", "1", "Bar", "7"]
```
